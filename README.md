# SEATBOOK

Event and seat booking platform built with Laravel. Organizers create events with seat layouts and ticket prices; attendees browse events, hold seats for 10 minutes, and confirm bookings.

## Features

- Registration and login for Organizers and Attendees (role-based access)
- Organizers: create, edit and manage events with seat arrangements and prices
- Attendees: browse events, view seat map, book seats
- Temporary seat hold (10 minutes) with countdown, auto-release of expired holds
- Booking management: view and cancel bookings

## Requirements

- PHP 8.2+ (check `php -v`)
- Composer
- MySQL (or SQLite)
- Node.js and npm (for frontend assets)
